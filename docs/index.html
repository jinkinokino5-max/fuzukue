図版
  1. 応用数学Ⅱ　葛飾北斎《諸国瀧廻り 木曽路ノ奥阿弥陀ヶ瀧》1833年頃、ロサンゼルス・カウンティ美術館／Public domain／Wikimedia Commons 円い滝口のまわりを水がぐるりと巡ってから落ちる。閉じた道をひと回りして値を拾う、周回積分と留数の見立て。
  2. 機械力学　葛飾北斎《諸国名橋奇覧 飛越の堺つりはし》1834年頃、メトロポリタン美術館／CC0／Wikimedia Commons 谷に張られた一本の吊橋を、荷を負った人が渡る。重さと張力とが釣り合っているあいだだけ、道はそこにある。
  3. 「今昔物語集」を読む　鳥山石燕《今昔百鬼拾遺》より「鬼一口」1780年／Public domain／Wikimedia Commons 在原業平の伊勢物語の段を、石燕は鬼の一口として描いた。題に「今昔」を戴いた妖怪画集で、説話が絵へ受け継がれた姿。
  4. 電磁気学　歌川広重《名所江戸百景 大はしあたけの夕立》1857年、米国議会図書館／Public domain／Wikimedia Commons 見えない雨脚を無数の線で描き、空間全体を満たすものとして見せる。力線で場を描くのと同じ手つき。
  5. 上代文学へのいざない　《元暦校本万葉集》巻一（部分）、平安時代、東京国立博物館／CC BY 4.0／出典：ColBase（Wikimedia Commons） 額田王の「莫囂円隣之大相七兄爪湯気…」。万葉仮名で書き留められながら、いまも定訓のない歌。歌が文字になって残った姿そのもの。
