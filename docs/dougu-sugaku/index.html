TOOLS OF MATHEMATICS

道具としての数学

研究室に入るまでに身につけたい数学を、記号を一つも省略せずに説明し直す自習資料。新しい記号は初めて出る場所で「読み方・意味・省略しない書き方」を説明し、前に出た記号や概念には、そのたびに説明の場所へのリンクをつける。

全体の骨格：記号と言葉 → 微積分 → 線形代数 → ベクトル解析 → 常微分方程式 → 複素数・フーリエ・ラプラス → 偏微分方程式 → 研究室の道具（確率統計・最小二乗・数値計算・最適化）。記号索引から、記号を初出の説明へ引ける。
