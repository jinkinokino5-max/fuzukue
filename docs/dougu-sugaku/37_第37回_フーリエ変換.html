1級数から変換へ：周期を限りなく長くする

1.1動機：周期のない波は、フーリエ級数では書けない

第36回のフーリエ級数は、周期 $T$ で同じ形を繰り返す関数を、周波数が $\omega_0,2\omega_0,3\omega_0,\dots$（$\omega_0=2\pi/T$）というとびとびの三角関数（複素指数関数）の和で書く道具だった。

ところが、研究室で出会う信号の多くは、繰り返さない。たとえば、ハンマーで一度だけ叩いた構造物の振動、一度だけ押したスイッチで流れる電流、一度だけ鳴る音の波形である。これらは周期がない。周期がないものに、周期 $T$ のフーリエ級数は使えない。

そこで考える。一度だけのパルスを、「ものすごく長い周期 $T$ の繰り返し」の1周期分だと思う。繰り返しの間隔を $T=2,4,8,\dots$ と伸ばしていけば、隣のパルスは遠ざかり、$T\to\infty$ では「繰り返しのない1つのパルス」になる。図1.1 のとおりである。

ひとことで周期のない関数は、「周期 $T$ が無限大の周期関数」と考える。そのとき、フーリエ級数の周波数の間隔 $\Delta\omega=2\pi/T$ は 0 に近づく。

1.2第36回の結果の確認：複素フーリエ級数の係数

（第36回で導いた結果をここで書き直す。覚えている人は 1.3 へ。）周期 $T$ の関数 $f$ は、$\omega_n:=n\omega_0=\dfrac{2\pi n}{T}$（$n=0,\pm1,\pm2,\dots$）として、次の形に書ける（第36回の複素フーリエ級数）。

$$f(t)=\sum_{n=-\infty}^{\infty}c_n\,e^{i\omega_nt},\qquad c_n=\frac1T\int_{-T/2}^{T/2}f(s)\,e^{-i\omega_ns}\,ds.$$

読み方：「$f(t)$ は、$n$ を $-\infty$ から $\infty$ まで動かした $c_n$ 掛ける $e^{i\omega_nt}$ の総和。$c_n$ は、$f(s)e^{-i\omega_ns}$ を1周期にわたって積分して $T$ で割ったもの」。ここで $e^{i\omega_nt}$ は第34回のオイラーの公式で $\cos\omega_nt+i\sin\omega_nt$ のことである。積分の変数を $s$ と書いたのは、左辺の $t$ と区別するため（積分変数は名前を変えてよい。第4回のダミー添字と同じ考え方）。

最小の具体例：幅 1 のパルス（1周期の中で $\lvert t\rvert<\frac12$ のとき $f=1$、それ以外は $0$）を考える。$T\,c_n$ は

$$T\,c_n=\int_{-1/2}^{1/2}e^{-i\omega_ns}ds=\Bigl[\frac{e^{-i\omega_ns}}{-i\omega_n}\Bigr]_{-1/2}^{1/2}=\frac{e^{i\omega_n/2}-e^{-i\omega_n/2}}{i\omega_n}=\frac{2\sin(\omega_n/2)}{\omega_n}.$$

各等号の理由は順に、①指数関数の積分（$\int e^{ks}ds=e^{ks}/k$、$k=-i\omega_n$）、②上端 $s=\frac12$ と下端 $s=-\frac12$ の値の差、③オイラーの公式から $e^{i\theta}-e^{-i\theta}=2i\sin\theta$（$\theta=\omega_n/2$）。ここで $n\ne0$（$\omega_n\ne0$）とした。

大事なのは、$T\,c_n=G(\omega_n)$ と書けることである。ここで $G(\omega):=\dfrac{2\sin(\omega/2)}{\omega}$ は $T$ によらない1本の曲線。周期 $T$ を変えると変わるのは、曲線の上のどの点 $\omega_n$ を取るか（間隔 $2\pi/T$）だけである。図1.2 で確かめる。

1.3導出：$T\to\infty$ で和が積分になる

1.2 の観察を一般の $f$ に広げる。1行に1操作で進める。

導出：級数から積分表示へ

① $G_T(\omega):=\displaystyle\int_{-T/2}^{T/2}f(s)\,e^{-i\omega s}\,ds$ とおく。　1.2 の $c_n$ の積分で、$\omega_n$ を一般の $\omega$ に置き換えただけ

② すると $c_n=\dfrac1T\,G_T(\omega_n)$。　1.2 の $c_n$ の式と ① を見比べる

③ よって $f(t)=\displaystyle\sum_{n=-\infty}^{\infty}\frac1T\,G_T(\omega_n)\,e^{i\omega_nt}$。　1.2 の級数の式に ② を代入

④ 隣り合う周波数の間隔は $\Delta\omega:=\omega_{n+1}-\omega_n=\dfrac{2\pi(n+1)}T-\dfrac{2\pi n}T=\dfrac{2\pi}T$。つまり $\dfrac1T=\dfrac{\Delta\omega}{2\pi}$。　$\omega_n$ の定義

⑤ ③ の $\frac1T$ に ④ を代入して $f(t)=\dfrac1{2\pi}\displaystyle\sum_{n=-\infty}^{\infty}G_T(\omega_n)\,e^{i\omega_nt}\,\Delta\omega$。　定数 $\frac1{2\pi}$ を前に出した

⑥ ⑤ の右辺はリーマン和（第10回）：横軸に $\omega$ をとり、幅 $\Delta\omega$、高さ $G_T(\omega_n)e^{i\omega_nt}$ の細い長方形を並べて面積を足したもの（図1.3）。

⑦ $T\to\infty$ とすると、$\Delta\omega=2\pi/T\to0$（長方形が細くなる）、かつ $G_T(\omega)\to G(\omega):=\displaystyle\int_{-\infty}^{\infty}f(s)\,e^{-i\omega s}\,ds$（積分範囲が全直線に広がる）。リーマン和は積分に近づく：

$$G(\omega)=\int_{-\infty}^{\infty}f(s)\,e^{-i\omega s}\,ds,\qquad f(t)=\frac1{2\pi}\int_{-\infty}^{\infty}G(\omega)\,e^{i\omega t}\,d\omega.\qquad(\ast)$$
注意：この導出は「筋道」であって証明ではない

⑦ では、「$T\to\infty$ と $\Delta\omega\to0$ の極限を同時に取り、極限と和（積分）の順序を入れ替えてよい」と仮定した。これが正当化できる条件（$f$ が絶対可積分で、区分的に滑らか）は 2.6 と 6.1 で述べる。この回では、条件を満たす関数にしか $(\ast)$ を使わない。

2.5なぜ $AB=\frac1{2\pi}$ でなければならないのか

記号の確認：定数の積 $AB$

前節の定数 $A$（変換）と $B$（逆変換）の積 $AB$ のこと。流派ごとに $A$ と $B$ は違うが、積は必ず $\dfrac1{2\pi}$ になる。

導出：$AB=\frac1{2\pi}$

① 1.3 の $(\ast)$ の $G(\omega)=\displaystyle\int f(s)e^{-i\omega s}ds$ に対して、$f(t)=\dfrac1{2\pi}\displaystyle\int G(\omega)e^{i\omega t}d\omega$ が成り立つ。　1.3 の結論

② 流派の変換は $\hat f(\omega)=A\,G(\omega)$。したがって $G(\omega)=\dfrac1A\hat f(\omega)$。　$A\ne0$ とする

③ ② を ① に代入：$f(t)=\dfrac1{2\pi A}\displaystyle\int\hat f(\omega)e^{i\omega t}d\omega$。

④ これが逆変換の形 $f(t)=B\displaystyle\int\hat f(\omega)e^{i\omega t}d\omega$ と一致するので、$B=\dfrac1{2\pi A}$。つまり $AB=\dfrac1{2\pi}$。□

周波数 $\xi$ の形（④）は、③ の $\omega$ を $2\pi\xi$ に置き換える（置換積分、$d\omega=2\pi\,d\xi$、第10回）。$A=1$ のとき、$f(t)=\dfrac1{2\pi}\displaystyle\int G(\omega)e^{i\omega t}d\omega=\dfrac1{2\pi}\displaystyle\int G(2\pi\xi)\,e^{2\pi i\xi t}\,2\pi\,d\xi=\displaystyle\int G(2\pi\xi)e^{2\pi i\xi t}d\xi$。よって $\xi$ の形では $2\pi$ が消えて、$A=B=1$ になる。

確かめ：$f(t)=e^{-\lvert t\rvert}$ の流派②の変換は $\dfrac{2}{1+\omega^2}$（3.2 で導く）。逆変換 $\dfrac1{2\pi}\int\dfrac{2}{1+\omega^2}d\omega$ の $t=0$ での値は $\dfrac1{2\pi}\cdot2\pi=1=f(0)$。実際、$\int_{-\infty}^{\infty}\frac{d\omega}{1+\omega^2}=[\arctan\omega]_{-\infty}^{\infty}=\pi$ なので一致する（`draft/check_37.py` でも数値で確認）。

ひとことで変換と逆変換の定数の積は必ず $\frac1{2\pi}$。配り方（$\sqrt{2\pi}$ ずつか、片方に寄せるか、$2\pi$ を指数に入れて $\xi$ で書くか）が流派。本を開いたら、$\omega=0$ での値で流派を見分ける。

2.6どんな関数に使えるか：絶対可積分

記号：絶対可積分 $\displaystyle\int_{-\infty}^{\infty}\lvert f(t)\rvert\,dt<\infty$

①読み方：「エフの絶対値の全直線の積分が有限」。「ぜったいかせきぶん」。

②日本語での意味：$\lvert f\rvert$ のグラフと横軸の間の面積が、有限の値になる。$f$ が両端で十分速くゼロに近づけばよい。

③省略していない書き方：$\lim_{M,L\to\infty}\int_{-M}^{L}\lvert f(t)\rvert\,dt$ が有限の実数。級数の絶対収束の積分版。

④どこで出会うか：フーリエ変換が存在する条件。確率密度は $\int p=1$ で自動的に満たす。

なぜ必要か。変換の被積分関数は $f(t)e^{-i\omega t}$ で、第34回のとおり $\lvert e^{-i\omega t}\rvert=1$ だから、$\lvert f(t)e^{-i\omega t}\rvert=\lvert f(t)\rvert$。したがって $\int\lvert f\rvert\,dt<\infty$ なら、どの $\omega$ でも変換の積分が（絶対収束して）有限の値に決まる。

よくある誤解

「$f$ が 0 に近づけばよい」は不十分。$f(t)=\dfrac1{1+\lvert t\rvert}$ は $t\to\pm\infty$ で 0 に近づくが、$\int\dfrac{dt}{1+\lvert t\rvert}$ は発散する（第14回のp級数 $p=1$ と同じ）ので絶対可積分でない。一方 $f=e^{-\lvert t\rvert}$ は両端で急速に減るので、面積は $2$ で有限。また、$f=1$（定数）や $f=\sin t$ は絶対可積分でない。これらの変換は第39回のデルタ関数で扱う（6.2 で予告）。

ひとことでこの回の変換は、$\int\lvert f\rvert\,dt$ が有限の関数に対して使う。$\lvert e^{-i\omega t}\rvert=1$ が、この条件で積分が有限になる理由。

2.7変換の意味：「巻き付けて平均を取る」

$\hat f(\omega)=\frac1{\sqrt{2\pi}}\int f(t)e^{-i\omega t}dt$ の意味を、図で見る。$e^{-i\omega t}$ は、第34回のとおり複素平面の単位円の上を時計回りに角速度 $\omega$ で回る点である。これに $f(t)$ を掛けた $f(t)e^{-i\omega t}$ は、「半径 $f(t)$ で回る点」になる。これを $t$ について足し合わせる（積分する）のが変換である。

$f(t)=\cos3t$ を例に、$0\le t\le4\pi$ で $\omega=3$ と $\omega=1$ を比べる。$\omega=3$ のときは、$f$ の振動と回転が同じ速さなので、半径が負になる（点が原点の反対側に出る）ときも、回転が半周ぶんずれていて、点の軌跡はいつも右寄りに偏る。$\omega=1$ のときは、軌跡が原点のまわりにほぼ均等に散って、平均が $0$ になる。図2.3 のとおりである。

式で確かめる（$\omega=3$）。$\cos3t=\dfrac{e^{3it}+e^{-3it}}2$（第34回 4.6）なので、$\cos3t\cdot e^{-3it}=\dfrac{1+e^{-6it}}2$。第2項は 1 周期ごとに平均 0 なので、平均は $\dfrac12$。これは図の黒い点の位置に一致する。$\omega=1$ では $\cos3t\cdot e^{-it}=\dfrac{e^{2it}+e^{-4it}}2$ で、どちらも平均が 0。

ひとことで$\hat f(\omega)$ は、「$f$ を周波数 $\omega$ で逆向きに回して平均を取った値」。$f$ の中に周波数 $\omega$ の成分があれば、回転が打ち消されて平均が 0 から離れる。成分がなければ、平均はほぼ 0。

3手を動かす：4つの基本的な変換

以後、定義は 2.2 の流派 ①：$\hat f(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int_{-\infty}^{\infty}f(t)\,e^{-i\omega t}\,dt$ とする。どの例も、(i) 関数、(ii) 積分を1行ずつ進める、(iii) 確かめ（$\omega=0$ の値、極限）の順に書く。

3.1矩形パルス → sinc

動機：スイッチを一定時間だけ入れる、という最も素朴な「一度だけの信号」。$a>0$ として

$$f(t)=\begin{cases}1&(\lvert t\rvert\lt a)\\0&(\lvert t\rvert\ge a)\end{cases}$$

（応用数学Ⅱ第10回の例10.2と同じ関数）。

導出

① $\hat f(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int_{-a}^{a}e^{-i\omega t}\,dt$。　$\lvert t\rvert\ge a$ では $f=0$ なので、積分は $[-a,a]$ だけ

② $=\dfrac1{\sqrt{2\pi}}\Bigl[\dfrac{e^{-i\omega t}}{-i\omega}\Bigr]_{-a}^{a}$。　$\omega\ne0$ とする。$\int e^{kt}dt=e^{kt}/k$、$k=-i\omega$

③ $=\dfrac1{\sqrt{2\pi}}\cdot\dfrac{e^{-i\omega a}-e^{i\omega a}}{-i\omega}$。　上端 $t=a$ と下端 $t=-a$ の値の差

④ $=\dfrac1{\sqrt{2\pi}}\cdot\dfrac{e^{i\omega a}-e^{-i\omega a}}{i\omega}$。　分子・分母に $-1$ を掛けた

⑤ $=\dfrac1{\sqrt{2\pi}}\cdot\dfrac{2i\sin(a\omega)}{i\omega}$。　オイラーの公式から $e^{i\theta}-e^{-i\theta}=2i\sin\theta$（第34回）

⑥ $=\dfrac{2}{\sqrt{2\pi}}\cdot\dfrac{\sin(a\omega)}{\omega}=\sqrt{\dfrac2\pi}\,\dfrac{\sin(a\omega)}{\omega}$。　$i$ を約分、$\dfrac2{\sqrt{2\pi}}=\sqrt{\dfrac{4}{2\pi}}=\sqrt{\dfrac2\pi}$

記号：$\operatorname{sinc}$（シンク関数）

①読み方：「シンク」。

②日本語での意味：「$\sin x$ を $x$ で割った関数」。$x=0$ のときだけ、極限の値 $1$ と決める。

③省略していない書き方：$\operatorname{sinc}x:=\dfrac{\sin x}{x}\ (x\ne0)$、$\operatorname{sinc}0:=1$（理由：極限 $\lim_{x\to0}\frac{\sin x}x=1$）。

④どこで出会うか：矩形パルスの変換、サンプリング定理（標本化）、光の回折。

流派の違い：sinc の定義

信号処理の本には $\operatorname{sinc}x:=\dfrac{\sin\pi x}{\pi x}$（$\pi$ が入る正規化 sinc）と定義するものがある。零点が整数 $x=\pm1,\pm2,\dots$ に来るのが利点。この回は $\pi$ なしの $\dfrac{\sin x}x$ に統一する。

⑥ を sinc で書くと $\hat f(\omega)=\sqrt{\dfrac2\pi}\,a\,\operatorname{sinc}(a\omega)$。

確かめ：(i) $\omega\to0$ の極限。$\dfrac{\sin(a\omega)}{\omega}=a\cdot\dfrac{\sin(a\omega)}{a\omega}\to a\cdot1$（$\lim_{x\to0}\frac{\sin x}x=1$、第6回）。よって $\hat f(0)=\sqrt{\frac2\pi}\,a=\dfrac{2a}{\sqrt{2\pi}}$。これは 2.2 の「$\hat f(0)=\frac1{\sqrt{2\pi}}\int f\,dt$、面積は $2a$」と一致する（$a=1$ で $0.798$）。(ii) 零点：$\sin(a\omega)=0$ すなわち $\omega=\pm\dfrac{\pi}{a},\pm\dfrac{2\pi}{a},\dots$。

図3.1 のとおり、パルスの幅 $2a$ を狭くすると、最初の零点 $\pi/a$ が遠くへ動き、$\hat f$ は横に広がる。幅が広いほど $\hat f$ は細く高い。これは 4.5 で一般の規則になる。

よくある誤解

「$\hat f(\omega)$ は $\omega>0$ だけ考えればよい」は、実関数が偶関数のときには数値の上で正しい（4.6）。ただし $f$ の形によっては $\hat f(-\omega)$ は $\hat f(\omega)$ の共役で、虚部の符号が違う（3.3）。負の周波数 $\omega<0$ は「逆向きに回る波」で、実数の波を $e^{i\omega t}$ で書くために必ず現れる（$\cos\theta=\frac{e^{i\theta}+e^{-i\theta}}2$）。

ひとことで幅 $2a$ のパルスの変換は $\sqrt{2/\pi}\,\sin(a\omega)/\omega$（sinc の形）。$\omega=0$ の値は面積 $/\sqrt{2\pi}$、零点は $\pi/a$ の整数倍、幅を狭くすると横に広がる。

3.2両側指数関数 $e^{-a\lvert t\rvert}$ → ローレンツ形

動機：「ゆっくり減衰して消える」信号。$a>0$ として $f(t)=e^{-a\lvert t\rvert}$。$\lvert t\rvert$ は $t\ge0$ で $t$、$t<0$ で $-t$ なので、積分を2つに分ける。

導出

① $\hat f(\omega)=\dfrac1{\sqrt{2\pi}}\Bigl[\displaystyle\int_{-\infty}^{0}e^{at}e^{-i\omega t}dt+\int_{0}^{\infty}e^{-at}e^{-i\omega t}dt\Bigr]$。　$t<0$ で $e^{-a\lvert t\rvert}=e^{at}$、$t\ge0$ で $e^{-at}$

② $=\dfrac1{\sqrt{2\pi}}\Bigl[\displaystyle\int_{-\infty}^{0}e^{(a-i\omega)t}dt+\int_{0}^{\infty}e^{-(a+i\omega)t}dt\Bigr]$。　指数法則 $e^xe^y=e^{x+y}$

③ 1つ目：$\Bigl[\dfrac{e^{(a-i\omega)t}}{a-i\omega}\Bigr]_{-\infty}^{0}=\dfrac{1-0}{a-i\omega}=\dfrac1{a-i\omega}$。　$t\to-\infty$ で $\lvert e^{(a-i\omega)t}\rvert=e^{at}\to0$（$a>0$、$\lvert e^{-i\omega t}\rvert=1$）

④ 2つ目：$\Bigl[\dfrac{e^{-(a+i\omega)t}}{-(a+i\omega)}\Bigr]_{0}^{\infty}=\dfrac{0-1}{-(a+i\omega)}=\dfrac1{a+i\omega}$。　$t\to\infty$ で $\lvert e^{-(a+i\omega)t}\rvert=e^{-at}\to0$

⑤ 和：$\dfrac1{a-i\omega}+\dfrac1{a+i\omega}=\dfrac{(a+i\omega)+(a-i\omega)}{(a-i\omega)(a+i\omega)}=\dfrac{2a}{a^2+\omega^2}$。　通分。分母は共役どうしの積 $(a-i\omega)(a+i\omega)=a^2-(i\omega)^2=a^2+\omega^2$（第34回）

⑥ $\hat f(\omega)=\dfrac1{\sqrt{2\pi}}\cdot\dfrac{2a}{a^2+\omega^2}=\sqrt{\dfrac2\pi}\,\dfrac{a}{a^2+\omega^2}$。

数値：$a=1$、$\omega=1$ で $\sqrt{2/\pi}\cdot\frac12\approx0.399$。確かめ：$\omega=0$ で $\sqrt{\frac2\pi}\cdot\frac1a$。面積は $\int e^{-a\lvert t\rvert}dt=\frac2a$ なので、$\frac1{\sqrt{2\pi}}\cdot\frac2a=\sqrt{\frac2\pi}\frac1a$ で一致する。$\hat f$ は実数で偶関数（$f$ が偶関数だから）。

応用数学Ⅱ第10回の例10.1は $f=\sqrt\alpha\,e^{-\alpha\lvert x\rvert}$ で、この結果に $\sqrt\alpha$ を掛けたものである。図3.2 のとおり、$a$ が大きい（速く減衰する、時間幅が狭い）ほど、$\hat f$ は低く広くなる。

ひとことで$e^{-a\lvert t\rvert}\ \to\ \sqrt{2/\pi}\;a/(a^2+\omega^2)$。分母の $a^2+\omega^2$ は共役を掛けた結果。$t=0$ のとがり（$\lvert t\rvert$ の折れ）のせいで、$\hat f$ は $1/\omega^2$ でしか減らない。

3.3片側指数関数 $e^{-at}$（$t>0$ のみ）→ 複素数の値

動機：スイッチを入れた時刻 $t=0$ から減衰する、実際の応答（第28回の $\dot y=-ay$ の解）。

$$f(t)=\begin{cases}e^{-at}&(t>0)\\0&(t\le0)\end{cases}\qquad(a>0).$$
導出

① $\hat f(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int_{0}^{\infty}e^{-at}e^{-i\omega t}dt$。　$t\le0$ で $f=0$

② $=\dfrac1{\sqrt{2\pi}}\displaystyle\int_{0}^{\infty}e^{-(a+i\omega)t}dt$。　指数法則

③ $=\dfrac1{\sqrt{2\pi}}\Bigl[\dfrac{e^{-(a+i\omega)t}}{-(a+i\omega)}\Bigr]_{0}^{\infty}=\dfrac1{\sqrt{2\pi}}\cdot\dfrac{0-1}{-(a+i\omega)}$。　3.2 の ④ と同じ

④ $\hat f(\omega)=\dfrac1{\sqrt{2\pi}}\cdot\dfrac1{a+i\omega}$。

今回の $\hat f$ は複素数。実部と虚部に分けるには、分母の共役を掛ける（第34回）：

$$\frac1{a+i\omega}=\frac{a-i\omega}{(a+i\omega)(a-i\omega)}=\frac{a-i\omega}{a^2+\omega^2}.$$

したがって $\operatorname{Re}\hat f=\dfrac1{\sqrt{2\pi}}\dfrac{a}{a^2+\omega^2}$、$\operatorname{Im}\hat f=-\dfrac1{\sqrt{2\pi}}\dfrac{\omega}{a^2+\omega^2}$。大きさと偏角は（$\lvert z\rvert$、$\arg z$）

$$\lvert\hat f(\omega)\rvert=\frac{1}{\sqrt{2\pi}}\cdot\frac1{\sqrt{a^2+\omega^2}},\qquad\arg\hat f(\omega)=-\arg(a+i\omega)=-\arctan\frac\omega a.$$

理由：分数の絶対値は絶対値の分数、$\arg(1/z)=-\arg z$（第34回：割り算は偏角の引き算）。

数値：$a=1$、$\omega=1$ で $\hat f=\dfrac{1}{\sqrt{2\pi}(1+i)}=\dfrac{1-i}{2\sqrt{2\pi}}\approx0.199-0.199\,i$。大きさ $\approx0.282$、偏角 $-45^\circ$。確かめ：$\omega=0$ で $\hat f(0)=\frac1{\sqrt{2\pi}\,a}$。面積 $\int_0^\infty e^{-at}dt=\frac1a$ を $\sqrt{2\pi}$ で割った値で一致する。

ひとことで$t=0$ から始まる減衰は $\hat f=\dfrac{1}{\sqrt{2\pi}\,(a+i\omega)}$。左右対称でない関数の変換は複素数になり、大きさ（どれだけ含むか）と偏角（どれだけずれて含むか）に分けて読む。

3.4ガウス関数 $e^{-t^2/2}$ → 同じ形のガウス関数

動機：自然界のばらつき（正規分布）の形。そしてこの関数は、変換しても同じ形に戻る特別な関数である。

導出：微分方程式を経由する

① $\hat f(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int_{-\infty}^{\infty}e^{-t^2/2}e^{-i\omega t}dt$ について、まず $\omega=0$：$\hat f(0)=\dfrac1{\sqrt{2\pi}}\displaystyle\int e^{-t^2/2}dt=\dfrac{\sqrt{2\pi}}{\sqrt{2\pi}}=1$。　ガウス積分 $\int e^{-t^2/2}dt=\sqrt{2\pi}$（第13回 7.4）

② $\omega$ で微分する：$\hat f'(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int e^{-t^2/2}(-it)\,e^{-i\omega t}dt$。　$\frac{\partial}{\partial\omega}e^{-i\omega t}=-it\,e^{-i\omega t}$。積分と微分の順序の入れ替えは、$e^{-t^2/2}$ が十分速く減るので許されるとする

③ $-t\,e^{-t^2/2}=\dfrac{d}{dt}e^{-t^2/2}$ だから、$-it\,e^{-t^2/2}=i\,\dfrac{d}{dt}e^{-t^2/2}$。　合成関数の微分（第7回）

④ $\hat f'(\omega)=\dfrac{i}{\sqrt{2\pi}}\displaystyle\int\Bigl(\dfrac{d}{dt}e^{-t^2/2}\Bigr)e^{-i\omega t}dt$。　③ を ② に代入

⑤ 部分積分（第10回）：$\displaystyle\int u'v\,dt=[uv]-\int uv'dt$、$u=e^{-t^2/2}$、$v=e^{-i\omega t}$。境界項 $[e^{-t^2/2}e^{-i\omega t}]_{-\infty}^{\infty}=0$（$e^{-t^2/2}\to0$、$\lvert e^{-i\omega t}\rvert=1$）、$v'=-i\omega\,e^{-i\omega t}$。よって

$$\hat f'(\omega)=\frac{i}{\sqrt{2\pi}}\Bigl(0-\int e^{-t^2/2}(-i\omega)e^{-i\omega t}dt\Bigr)=\frac{i\cdot i\omega}{\sqrt{2\pi}}\int e^{-t^2/2}e^{-i\omega t}dt.$$

⑥ 右辺の積分に $\frac1{\sqrt{2\pi}}$ を付けたものが $\hat f(\omega)$ だから、$\hat f'(\omega)=i\cdot i\omega\,\hat f(\omega)=-\omega\,\hat f(\omega)$。　$i\cdot i=-1$

⑦ 微分方程式 $\hat f'=-\omega\hat f$ を変数分離（第28回）で解く：$\dfrac{d\hat f}{\hat f}=-\omega\,d\omega$、$\ln\lvert\hat f\rvert=-\dfrac{\omega^2}2+C'$、$\hat f=Ce^{-\omega^2/2}$。① の $\hat f(0)=1$ から $C=1$。

$$\boxed{\ \mathcal F\bigl[e^{-t^2/2}\bigr](\omega)=e^{-\omega^2/2}\ }\qquad\Bigl(\text{一般に }\mathcal F\bigl[e^{-\alpha t^2}\bigr](\omega)=\frac1{\sqrt{2\alpha}}\,e^{-\omega^2/(4\alpha)}\ (\alpha>0)\Bigr).$$

2つ目の式は、4.5 の伸縮の規則に $c=\sqrt{2\alpha}$ を入れて得られる（演習問題 9）。確かめ：$\omega=0$ で $\frac1{\sqrt{2\alpha}}$。面積 $\int e^{-\alpha t^2}dt=\sqrt{\pi/\alpha}$ を $\sqrt{2\pi}$ で割ると $\sqrt{\dfrac{\pi}{\alpha\cdot2\pi}}=\dfrac1{\sqrt{2\alpha}}$ で一致する。

注意

「変換しても同じ形になる」のは、流派 ① で $e^{-t^2/2}$ のときだけ。流派 ② では $\sqrt{2\pi}\,e^{-\omega^2/2}$（$\sqrt{2\pi}$ 倍）、流派 ④ では $e^{-\pi t^2}\to e^{-\pi\xi^2}$ が自己相似になる。どの関数が自分自身に戻るかも、流派で変わる。

ひとことでガウス関数 $e^{-t^2/2}$ は流派 ① の変換で自分自身に戻る。導出の鍵は、「$t$ を掛けること」が「$\omega$ で微分すること」に、「$t$ で微分すること」が「$i\omega$ を掛けること」に対応する、という双対（4.4）。

4.1線形性

積分は和と定数倍を保つ（第10回）ので、$\displaystyle\int(c_1f_1+c_2f_2)e^{-i\omega t}dt=c_1\int f_1e^{-i\omega t}dt+c_2\int f_2e^{-i\omega t}dt$。両辺に $\frac1{\sqrt{2\pi}}$ を掛けて、$\mathcal F[c_1f_1+c_2f_2]=c_1\mathcal F[f_1]+c_2\mathcal F[f_2]$。

4.2時間をずらす → 位相が回る

動機：同じ形の信号が、時刻 $t_0$ だけ遅れて来たらどうなるか。

導出：$g(t):=f(t-t_0)$

① $\hat g(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int f(t-t_0)\,e^{-i\omega t}dt$。　定義 S0

② $s:=t-t_0$ と置換する。$t=s+t_0$、$dt=ds$、積分範囲は変わらない。　置換積分（第10回）

③ $\hat g(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int f(s)\,e^{-i\omega(s+t_0)}ds$。

④ $e^{-i\omega(s+t_0)}=e^{-i\omega s}e^{-i\omega t_0}$、後ろの因子は $s$ によらないので積分の外へ。　指数法則、定数倍は積分の外へ

⑤ $\hat g(\omega)=e^{-i\omega t_0}\cdot\dfrac1{\sqrt{2\pi}}\displaystyle\int f(s)e^{-i\omega s}ds=e^{-i\omega t_0}\,\hat f(\omega)$。　積分変数の名前は $s$ でも $t$ でもよい

$\lvert e^{-i\omega t_0}\rvert=1$ なので、大きさ $\lvert\hat g\rvert=\lvert\hat f\rvert$ は変わらず、偏角が $-\omega t_0$ だけ変わる。偏角の変化は $\omega$ に比例する（遅れが大きいほど、高い周波数ほど大きく回る）。図4.1 で、ガウス関数を $t_0=1$ ずらして確かめる。

確かめ：3.4 の結果 $\hat f=e^{-\omega^2/2}$ から、$f(t-1)$ の変換は $e^{-i\omega}e^{-\omega^2/2}$ となる。偏角は $-\omega$（図の直線）、大きさは $e^{-\omega^2/2}$ のまま（`draft/check_37.py` で数値積分と比べて確認）。

4.3周波数をずらす（変調）

$g(t):=e^{i\omega_0t}f(t)$ とする。

導出

① $\hat g(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int e^{i\omega_0t}f(t)e^{-i\omega t}dt$。　定義 S0

② $e^{i\omega_0t}e^{-i\omega t}=e^{-i(\omega-\omega_0)t}$。　指数法則

③ $\hat g(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int f(t)e^{-i(\omega-\omega_0)t}dt=\hat f(\omega-\omega_0)$。　③ の右辺は、$\hat f$ の定義の $\omega$ を $\omega-\omega_0$ に置き換えたもの

実際の信号は実数なので、$\cos\omega_0t$ を使う。$\cos\omega_0t=\dfrac{e^{i\omega_0t}+e^{-i\omega_0t}}2$ と線形性（4.1）から

$$\mathcal F[f(t)\cos\omega_0t](\omega)=\frac12\bigl[\hat f(\omega-\omega_0)+\hat f(\omega+\omega_0)\bigr].$$

意味：$\hat f$ の山が、$\omega=+\omega_0$ と $\omega=-\omega_0$ の2か所に、高さ半分で分かれて現れる（5.1 の図5.1）。ラジオの変調はこの規則で、低い周波数の音を高い周波数の「搬送波」に載せる。

4.4微分は $i\omega$ 倍、$t$ を掛けると $\omega$ での微分

動機：微分方程式（第28〜30回）を、周波数の側で代数方程式にできないか。

導出：$\mathcal F[f']=i\omega\hat f$

① $\mathcal F[f'](\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int f'(t)\,e^{-i\omega t}dt$。　定義 S0

② 部分積分：$u=f$、$v=e^{-i\omega t}$ として $\displaystyle\int u'v\,dt=[uv]_{-\infty}^{\infty}-\int uv'\,dt$。　第10回の部分積分

③ 境界項 $[f(t)e^{-i\omega t}]_{-\infty}^{\infty}=0$。　$f(t)\to0$（$t\to\pm\infty$）、$\lvert e^{-i\omega t}\rvert=1$

④ $v'=-i\omega\,e^{-i\omega t}$ なので、$\displaystyle\int f'e^{-i\omega t}dt=0-\int f(t)(-i\omega)e^{-i\omega t}dt=i\omega\int f(t)e^{-i\omega t}dt$。　$-(-i\omega)=i\omega$、定数は外へ

⑤ 両辺に $\frac1{\sqrt{2\pi}}$ を掛けて $\mathcal F[f']=i\omega\,\hat f(\omega)$。□

導出：$\mathcal F[t\,f]=i\,\hat f'$

① $\hat f'(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int f(t)\,(-it)\,e^{-i\omega t}dt=-i\,\mathcal F[t\,f](\omega)$。　$\hat f$ の定義を $\omega$ で微分（3.4 ② と同じ。順序の入れ替えは $t\,f(t)$ も絶対可積分と仮定）

② 両辺に $i$ を掛ける：$i\,\hat f'=i\cdot(-i)\mathcal F[tf]=\mathcal F[tf]$。　$i\cdot(-i)=-i^2=1$

2回微分すれば $\mathcal F[f'']=(i\omega)^2\hat f=-\omega^2\hat f$。これを繰り返せば、$n$ 階の微分は $(i\omega)^n$ 倍になる。微分方程式の「微分」が、周波数の側では「$i\omega$ を掛ける」掛け算になる。7章はこれを使う。

確かめ：$f=e^{-t^2/2}$、$f'=-t\,e^{-t^2/2}$。左辺 $\mathcal F[f']$ は 4.4 の2つ目の規則（符号に注意）で $-\mathcal F[tf]=-i\hat f'=-i\cdot(-\omega e^{-\omega^2/2})=i\omega\,e^{-\omega^2/2}$。右辺 $i\omega\hat f=i\omega e^{-\omega^2/2}$。一致する。

よくある誤解

(i) $\mathcal F[f']=i\omega\hat f$ は、$f(t)\to0$（$t\to\pm\infty$）のときの規則。境界項が消えない関数（たとえば定数や $\sin t$）では成り立たない。(ii) 符号 $e^{+i\omega t}$ の流派 ⑤ では、微分が $-i\omega$ 倍になる。工学の本で $j\omega$、物理の本で $-i\omega$ と書かれるのは、この符号の違い（2.4）。

4.5伸縮：時間を縮めると周波数は広がる

$c>0$ として $g(t):=f(ct)$。$c>1$ なら、グラフを横に $\frac1c$ 倍に縮めたもの（時間が速く進む）。

導出

① $\hat g(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int f(ct)\,e^{-i\omega t}dt$。　定義 S0

② $s:=ct$ と置換。$t=s/c$、$dt=ds/c$（$c>0$ なので積分範囲の向きは変わらない）。　置換積分

③ $\hat g(\omega)=\dfrac1{\sqrt{2\pi}}\displaystyle\int f(s)\,e^{-i(\omega/c)s}\dfrac{ds}c$。　$\omega t=\omega s/c$

④ $=\dfrac1c\cdot\dfrac1{\sqrt{2\pi}}\displaystyle\int f(s)e^{-i(\omega/c)s}ds=\dfrac1c\,\hat f\!\left(\dfrac\omega c\right)$。　$\hat f$ の定義の $\omega$ を $\omega/c$ に置き換えたもの

数値：$f=e^{-t^2/2}$ に $c=2$：$g(t)=e^{-2t^2}$。$\hat g(\omega)=\frac12e^{-\omega^2/8}$。確かに 3.4 の一般形（$\alpha=2$：$\frac1{\sqrt4}e^{-\omega^2/8}$）と一致する。

記号・法則：時間幅と周波数幅の積

図4.2 のとおり、時間の側で幅が $\frac1c$ 倍に縮むと、周波数の側で幅が $c$ 倍に広がり、高さは $\frac1c$ 倍に下がる。ガウス関数で、$f$ の幅を「$\lvert f\rvert^2$ の標準偏差」$\sigma_t$、$\hat f$ の幅を「$\lvert\hat f\rvert^2$ の標準偏差」$\sigma_\omega$ とすると、$\sigma_t\sigma_\omega=\dfrac12$（計算は演習問題 10）で、$c$ によらない一定値になる。一般の関数では $\sigma_t\sigma_\omega\ge\dfrac12$ という不等式（不確定性関係）が成り立つことが知られており、ガウス関数は等号を達成する。この不等式の証明は本回では扱わない。

応用数学Ⅱ第10回の 10.8 の時間幅と周波数幅のトレードオフは、この規則の表れである。

4.6$f$ が実数値のとき：$\hat f(-\omega)=\overline{\hat f(\omega)}$

現実の信号は実数なので、この性質が最もよく使われる。

導出

① $f$ が実数値なら $\overline{f(t)}=f(t)$。　実数の共役は自分自身

② $\overline{\hat f(\omega)}=\overline{\dfrac1{\sqrt{2\pi}}\displaystyle\int f(t)e^{-i\omega t}dt}=\dfrac1{\sqrt{2\pi}}\displaystyle\int\overline{f(t)}\,\overline{e^{-i\omega t}}\,dt$。　共役は和・積を保つ。積分は和の極限なので、共役は積分の中に入る（第34回）

③ $\overline{e^{-i\omega t}}=e^{i\omega t}$（$\cos\omega t-i\sin\omega t$ の共役は $\cos\omega t+i\sin\omega t$）。　オイラーの公式と共役（第34回）

④ よって $\overline{\hat f(\omega)}=\dfrac1{\sqrt{2\pi}}\displaystyle\int f(t)e^{i\omega t}dt=\dfrac1{\sqrt{2\pi}}\displaystyle\int f(t)e^{-i(-\omega)t}dt=\hat f(-\omega)$。□

帰結：(a) $\lvert\hat f(-\omega)\rvert=\lvert\hat f(\omega)\rvert$（振幅は偶関数）。(b) $\arg\hat f(-\omega)=-\arg\hat f(\omega)$（位相は奇関数）。(c) $\operatorname{Re}\hat f$ は偶、$\operatorname{Im}\hat f$ は奇。さらに $f$ が偶関数（$f(-t)=f(t)$）なら $\hat f$ は実数値の偶関数（3.1、3.2）、$f$ が実数値の奇関数（$f(-t)=-f(t)$）なら $\hat f$ は純虚数の奇関数（例題2）。実関数のスペクトルは、$\omega\ge0$ の側だけ描いても情報が欠けない。

ひとことでずらす（時間）＝位相を回す（周波数）、変調（周波数のずらし）、微分＝$i\omega$ 倍、縮める＝広がる、実関数＝ $\hat f(-\omega)=\overline{\hat f(\omega)}$。7つの規則は、すべて「定義の積分に、置換積分か部分積分を1回かける」ことで導かれる。

5スペクトルとパーセバルの等式

5.1スペクトル：どの周波数が、どれだけあるか

記号：スペクトル（振幅スペクトル $\lvert\hat f\rvert$、位相スペクトル $\arg\hat f$）

①読み方：「ふくそう・スペクトル」。振幅スペクトルは「エフ・ハット・オメガの絶対値」、位相スペクトルは「エフ・ハット・オメガの偏角」。

②日本語での意味：$\hat f(\omega)$ は複素数なので、(i) 大きさ $\lvert\hat f(\omega)\rvert$＝周波数 $\omega$ の成分の強さ、(ii) 偏角 $\arg\hat f(\omega)$＝その成分の波のずれ、の2つの実数の関数に分けて見る。

③省略していない書き方：$\hat f(\omega)=\lvert\hat f(\omega)\rvert\,e^{i\arg\hat f(\omega)}$（第34回の極形式）。$\lvert\hat f(\omega)\rvert^2$ をパワースペクトルという。

④どこで出会うか：振動の解析（FFT）、音の分析、ノイズの評価。

実例：$f(t)=e^{-a\lvert t\rvert}\cos\omega_0t$（減衰する振動）。4.3 の規則と 3.2 の結果から

$$\hat f(\omega)=\frac12\bigl[\hat g(\omega-\omega_0)+\hat g(\omega+\omega_0)\bigr],\qquad\hat g(\omega)=\sqrt{\frac2\pi}\frac{a}{a^2+\omega^2}.$$

$a=0.5$、$\omega_0=5$ のとき、スペクトルは $\omega=\pm5$ に山を持ち、山の幅（半値の幅）は減衰の速さ $a$ で決まる。図5.1 のとおり、波形に現れる振動数が、スペクトルの山の位置として読める。これが、研究室で加速度計の信号を FFT にかける理由である。

5.2周波数 $\omega$ と Hz

図5.1 の山の位置は $\omega_0=5\ \mathrm{rad/s}$。これは 2.4 のとおり $\xi=\dfrac{5}{2\pi}\approx0.80\ \mathrm{Hz}$（1秒に約0.8回の振動）である。FFT の結果のグラフの横軸が rad/s なのか Hz なのかは、必ず軸の単位を見て確かめる。

5.3パーセバルの等式：エネルギーは変換で変わらない

記号：パーセバルの等式（プランシュレルの定理）

①読み方：「パーセバルのとうしき」。

②日本語での意味：時間の側で $\lvert f\rvert^2$ を全部足したもの（エネルギー）と、周波数の側で $\lvert\hat f\rvert^2$ を全部足したものは、等しい。

③省略していない書き方（流派 ①）：$\displaystyle\int_{-\infty}^{\infty}\lvert f(t)\rvert^2dt=\int_{-\infty}^{\infty}\lvert\hat f(\omega)\rvert^2d\omega$。流派 ② では右辺に $\dfrac1{2\pi}$ が付く（2.5 の $AB=\frac1{2\pi}$ のため。演習問題 8）。

④どこで出会うか：信号のエネルギーの評価、級数版（$\sum\lvert c_n vert^2$）の対応する等式、量子力学の確率の規格化。

導出（筋道。積分の順序交換は仮定する）

① 逆変換（反転定理、6.1）で $f(t)=\dfrac1{\sqrt{2\pi}}\displaystyle\int\hat f(\omega)e^{i\omega t}d\omega$。　条件を満たす $f$

② 共役をとって $\overline{f(t)}=\dfrac1{\sqrt{2\pi}}\displaystyle\int\overline{\hat f(\omega)}\,e^{-i\omega t}d\omega$。　4.6 ③ と同じ計算

③ $\displaystyle\int\lvert f\rvert^2dt=\int f(t)\overline{f(t)}dt=\int f(t)\Bigl[\frac1{\sqrt{2\pi}}\int\overline{\hat f(\omega)}e^{-i\omega t}d\omega\Bigr]dt$。　$\lvert z\rvert^2=z\bar z$。② を代入

④ 積分の順序を入れ替える（フビニ、第13回の累次積分と同じ考え方）：$=\displaystyle\int\overline{\hat f(\omega)}\Bigl[\frac1{\sqrt{2\pi}}\int f(t)e^{-i\omega t}dt\Bigr]d\omega$。

⑤ 角括弧の中は $\hat f(\omega)$ の定義そのもの：$=\displaystyle\int\overline{\hat f(\omega)}\,\hat f(\omega)\,d\omega=\int\lvert\hat f(\omega)\rvert^2d\omega$。□

数値の確かめ：$f=e^{-a\lvert t\rvert}$ で、左辺 $\int e^{-2a\lvert t\rvert}dt=\dfrac1a$。右辺 $\displaystyle\int\frac2\pi\frac{a^2}{(a^2+\omega^2)^2}d\omega$。$\omega=a\tan\theta$ と置換すると $\displaystyle\int_{-\pi/2}^{\pi/2}\frac2\pi\frac{a^2\cdot a\sec^2\theta}{a^4\sec^4\theta}d\theta=\frac{2}{\pi a}\int_{-\pi/2}^{\pi/2}\cos^2\theta\,d\theta=\frac2{\pi a}\cdot\frac\pi2=\frac1a$。一致する（数値積分でも確認）。

ひとことで$\hat f(\omega)$ をスペクトル（強さと位相）と読む。実関数ではスペクトルは $\omega$ について対称。エネルギーは変換しても変わらない（パーセバル、流派 ① では係数なし）。

6逆変換が成り立つ条件

6.1反転定理

動機：1.3 は筋道であって証明ではなかった。「変換して逆変換すると $f$ に戻る」は、どんな関数で、どんな意味で成り立つのか。

定理：反転定理（フーリエの積分定理）

①読み方：「はんてんていり」。

②日本語での意味：$f$ が絶対可積分（2.6）で区分的に滑らか（グラフがなめらかな曲線のつなぎで、ジャンプは有限個）なら、変換してから逆変換すると、$f$ が連続な点では $f(t)$ に戻り、ジャンプしている点では、左右の極限の平均に戻る。

③省略していない書き方（流派 ①）：

$$\lim_{L\to\infty}\frac1{\sqrt{2\pi}}\int_{-L}^{L}\hat f(\omega)\,e^{i\omega t}\,d\omega=\frac{f(t+0)+f(t-0)}2.$$

ここで $f(t+0):=\lim_{s\to t,\,s>t}f(s)$、$f(t-0)$ は左からの極限（第6回の片側極限）。

④どこで出会うか：応用数学Ⅱ第10回の 10.6「変換できる条件」。第36回のフーリエ級数の収束定理（不連続点で左右の平均）の積分版。

（この定理の証明は本回では扱わない。応用数学Ⅱ第10回でも条件のみを述べている。）

注意点が1つある。$\hat f$ 自体は絶対可積分とは限らない。たとえば 3.1 の矩形の変換 $\sqrt{2/\pi}\,\sin(a\omega)/\omega$ は、$\int\bigl\lvert\frac{\sin a\omega}\omega\bigr\rvert d\omega$ が発散する。そのため逆変換の積分は、$\int_{-\infty}^{\infty}$ ではなく$\int_{-L}^{L}$ を作って $L\to\infty$ と書く（上の③）。この極限は存在して、上の値になる。

図6.1 は、矩形パルス（$a=1$）の変換 $\hat f$ を、$\lvert\omega\rvert\le\Omega$ の範囲だけ使って逆変換した結果である。計算は $\dfrac1\pi\bigl[\operatorname{Si}(\Omega(1+t))+\operatorname{Si}(\Omega(1-t))\bigr]$（$\operatorname{Si}x:=\int_0^x\frac{\sin u}u\,du$）。$\Omega$ を大きくすると矩形に近づき、ジャンプの点 $t=\pm1$ ではちょうど $\frac12$、ジャンプの近くでは飛び出す（$\Omega=20$ で約 8%、$\Omega\to\infty$ でも約 9% に近づくだけで消えない）。これは第36回のギブス現象と同じものである。

ひとことで反転定理：絶対可積分で区分的に滑らかな $f$ は、変換→逆変換で戻る。ジャンプの点では左右の平均に戻る。逆変換の積分は $\int_{-L}^{L}$ の極限として読む。

6.2条件を満たさない関数：定数、正弦波

$f(t)=1$ は絶対可積分でない（$\int_{-\infty}^{\infty}1\,dt$ は発散）ので、定義の積分 $\int e^{-i\omega t}dt$ は、どの $\omega$ でも収束しない。しかし直観的には、定数は「周波数 0 だけの波」なので、変換は $\omega=0$ にだけ立つ無限に高く細い山であるはずだ。これを正確に書く道具がデルタ関数で、第39回で扱う。ここでは、その方向に近づく様子だけを見る。$g_a(t)=e^{-a\lvert t\rvert}$ で $a\to0$ とすると、$g_a\to1$（どの $t$ でも）。一方、3.2 より $\hat g_a(0)=\sqrt{2/\pi}\,\frac1a\to\infty$ で、山は細くなりながら、面積 $\int\hat g_a\,d\omega=\sqrt{2\pi}$ は一定（演習で確認）。

よくある誤解

「定数関数 $f=1$ のフーリエ変換は 0」は誤り。ほとんどの $\omega$ で 0 だが、$\omega=0$ に無限に高い山がある（面積は $\sqrt{2\pi}$）。「変換が存在しない」と覚えて、条件を確かめる習慣をつける。

7使う：微分方程式が掛け算になる

7.11階の線形微分方程式 $y'+ay=f$

動機：第28・30回では、微分方程式を「解の形を仮定して」解いた。4.4 の規則を使うと、微分方程式が周波数の側の掛け算になる。$a>0$ として

$$y'(t)+a\,y(t)=f(t)\qquad(\ast\ast)$$

を考える（第28回の 1 階線形。$f$ が入力、$y$ が出力）。

導出

① $(\ast\ast)$ の両辺をフーリエ変換する。　$y,f$ は絶対可積分で、$y(t)\to0$（$t\to\pm\infty$）とする

② 左辺は線形性（4.1）で $\mathcal F[y']+a\,\mathcal F[y]$。　和と定数倍

③ 微分の規則（4.4）で $\mathcal F[y']=i\omega\,\hat y(\omega)$。　$y\to0$ の仮定を使った

④ $i\omega\,\hat y+a\,\hat y=\hat f$、すなわち $(a+i\omega)\,\hat y(\omega)=\hat f(\omega)$。　$\hat y$ でくくった

⑤ $\hat y(\omega)=\dfrac{1}{a+i\omega}\,\hat f(\omega)$。　$a+i\omega\ne0$（$a>0$ なので、どの実数 $\omega$ でも $\ne0$）

記号：$H(i\omega)=\dfrac1{a+i\omega}$（1階系の周波数応答）

①読み方：「エイチ・アイ・オメガ」。

②日本語での意味：入力のスペクトル $\hat f(\omega)$ に掛けると出力のスペクトル $\hat y(\omega)$ になる、周波数ごとの倍率（複素数）。

③省略していない書き方：$\hat y(\omega)=H(i\omega)\,\hat f(\omega)$、$H(i\omega):=\dfrac1{a+i\omega}$。$i\omega$ という形で書くのは、微分が $i\omega$ 倍になることから。第34回の周波数応答 $H(i\omega)$と同じもの。

④どこで出会うか：第38回のラプラス変換（$i\omega$ を $s$ に置き換えたものが伝達関数）、第39回、制御工学。

数値：$a=2$、$\omega=1.5$：$H=\dfrac1{2+1.5i}=\dfrac{2-1.5i}{4+2.25}=0.32-0.24\,i$。$\lvert H\rvert=0.4$、$\arg H=-\arctan\frac{1.5}{2}\approx-0.6435\ \mathrm{rad}\approx-36.9^\circ$。これは、入力 $\cos1.5t$ に対する定常解が $0.4\cos(1.5t-0.6435)$（振幅 0.4、位相が $0.6435$ 遅れ）になることを意味する（第30回の位相の遅れと定常解。数値積分でも確認）。

図7.1 のとおり、$\lvert H\rvert$ は $\omega$ が大きいほど小さい（高い周波数の入力を弱める＝低域通過）。$y'+ay=f$ は、速く変わる入力に出力がついていけない系である。第30回の 2 階の系なら、$H(i\omega)=\dfrac1{k-m\omega^2+ic\omega}$ の形で、同じ手順で出る（応用数学Ⅱ第11回 11.4に、フーリエ変換の微分方程式への応用がある）。

7.2戻す：逆変換は、変換の表を逆に読む

$\hat y$ が求まったら、逆変換で $y$ に戻す。逆変換の積分を直接計算せず、3章の結果を逆向きに読むのが基本である。たとえば 3.3 より、$\dfrac{1}{\sqrt{2\pi}\,(a+i\omega)}$ の逆変換は片側指数関数 $e^{-at}$（$t>0$）。この読み方を、章末例題 4 で実行する。

ひとことで微分方程式の両辺を変換すると、微分が $i\omega$ 倍になって代数方程式になる。$\hat y=H(i\omega)\hat f$ の $H$ が周波数応答。解は、$\hat y$ を表で逆に読んで戻す。

8フーリエ級数との対応と、次の回へ

フーリエ級数（第36回）フーリエ変換（この回）
対象周期 $T$ の関数周期のない関数（$T\to\infty$）
周波数とびとび $\omega_n=\frac{2\pi n}T$連続 $\omega\in\mathbb R$
成分を出す係数 $c_n=\frac1T\int_{-T/2}^{T/2}fe^{-i\omega_nt}dt$$\hat f(\omega)=\frac1{\sqrt{2\pi}}\int fe^{-i\omega t}dt$

（級数側の等式 $\frac1T\int\lvert f\rvert^2dt=\sum\lvert c_n\rvert^2$ は、5.3 の導出の積分を和に置き換えた形で得られる。）

次の回への予告（この回では扱わない）
  • 第38回 ラプラス変換：$t>0$ だけを考え、$e^{-i\omega t}$ を $e^{-st}$ に広げる（$s=i\omega$ が今回の $i\omega$）。絶対可積分でない関数（定数、$e^{t}$ など）も扱える。
  • 第39回 たたみ込み・デルタ関数・伝達関数：$\hat y=H\hat f$ の積が、時間の側ではたたみ込みになる。定数や $\sin t$ の変換もデルタ関数で書ける。
  • 離散フーリエ変換（DFT）と FFT：計測器は連続の $f(t)$ でなく、等間隔の標本 $f(t_0),f(t_1),\dots$ しか持たない。標本に対する変換が DFT で、それを速く計算する方法が FFT。第48回の数値計算の回と関係するが、この教材では詳しく扱わない（FFT の出力の係数の付け方も、ソフトウェアごとに流派がある）。

例題1（A：ずらした矩形）

$f(t)=\begin{cases}1&(0<t<2)\\0&(\text{それ以外})\end{cases}$ のフーリエ変換 $\hat f(\omega)$（流派 ①）を、3.1 の結果と 4.2 の規則で求め、$\lvert\hat f\rvert$ を述べよ。

解答　① $f(t)=g(t-1)$、$g(t)=\begin{cases}1&(\lvert t\rvert<1)\\0&(\lvert t\rvert\ge1)\end{cases}$（3.1 で $a=1$）。　区間 $(0,2)$ は区間 $(-1,1)$ を右へ 1 ずらしたもの

② $\hat g(\omega)=\sqrt{\dfrac2\pi}\dfrac{\sin\omega}{\omega}$。　3.1

③ 4.2 で $t_0=1$：$\hat f(\omega)=e^{-i\omega}\sqrt{\dfrac2\pi}\dfrac{\sin\omega}\omega$。

④ $\lvert\hat f\rvert=\Bigl\lvert\sqrt{\dfrac2\pi}\dfrac{\sin\omega}\omega\Bigr\rvert$。　$\lvert e^{-i\omega}\rvert=1$。ずらしても大きさは変わらない

確かめ：$\omega=0$ で $\hat f(0)=\sqrt{2/\pi}$。面積 2 を $\sqrt{2\pi}$ で割った値 $\frac{2}{\sqrt{2\pi}}=\sqrt{\frac2\pi}$ と一致する。直接積分すると $\frac1{\sqrt{2\pi}}\int_0^2e^{-i\omega t}dt=\frac1{\sqrt{2\pi}}\frac{1-e^{-2i\omega}}{i\omega}=\frac{e^{-i\omega}}{\sqrt{2\pi}}\frac{e^{i\omega}-e^{-i\omega}}{i\omega}$ で同じ。□

例題2（B：$t$ を掛ける）

$f(t)=t\,e^{-\lvert t\rvert}$ の変換を、$g(t)=e^{-\lvert t\rvert}$ の変換から求めよ。

解答　① 3.2 で $a=1$：$\hat g(\omega)=\sqrt{\dfrac2\pi}\dfrac{1}{1+\omega^2}$。

② 4.4：$\mathcal F[t\,g]=i\,\hat g'(\omega)$。　$t$ を掛ける ＝ $i\times$（$\omega$ で微分）

③ $\hat g'(\omega)=\sqrt{\dfrac2\pi}\cdot\dfrac{-2\omega}{(1+\omega^2)^2}$。　商の微分（第7回）: $\bigl(\frac1{1+\omega^2}\bigr)'=-\frac{2\omega}{(1+\omega^2)^2}$

④ $\hat f(\omega)=-i\sqrt{\dfrac2\pi}\dfrac{2\omega}{(1+\omega^2)^2}$。　② に ③ を代入

確かめ：$f$ は奇関数（$f(-t)=-f(t)$）なので、変換は純虚数で奇関数になるはず（4.6 の帰結：実・奇な $f$ では $\hat f$ は純虚数）。④ は純虚数で、$\omega$ の奇関数。$\omega=0$ で 0（$f$ の面積は 0）。□

例題3（B：ずらして変調する）

$f(t)=e^{-\lvert t-2\rvert}\cos3t$ の変換を求めよ。

解答　① $h(t):=e^{-\lvert t-2\rvert}=g(t-2)$、$g(t)=e^{-\lvert t\rvert}$。　2 だけ右へずらした

② 4.2：$\hat h(\omega)=e^{-2i\omega}\hat g(\omega)=e^{-2i\omega}\sqrt{\dfrac2\pi}\dfrac1{1+\omega^2}$。　3.2、$a=1$

③ $f=h(t)\cos3t$ なので 4.3 で、$\hat f(\omega)=\dfrac12\bigl[\hat h(\omega-3)+\hat h(\omega+3)\bigr]$。

④ 代入：$\hat f(\omega)=\dfrac12\sqrt{\dfrac2\pi}\Bigl[\dfrac{e^{-2i(\omega-3)}}{1+(\omega-3)^2}+\dfrac{e^{-2i(\omega+3)}}{1+(\omega+3)^2}\Bigr]$。

確かめ：$\lvert\hat f(\omega)\rvert$ は $\omega\approx\pm3$ に山を持つ（分母が小さくなる）。$f$ は実数値なので $\hat f(-\omega)=\overline{\hat f(\omega)}$（4.6）。④ で $\omega\to-\omega$ とすると指数の符号が反転して共役になっていることが確かめられる。□

例題4（B：微分方程式を変換で解く）

$y'+2y=f(t)$、$f(t)=\begin{cases}e^{-t}&(t>0)\\0&(t\le0)\end{cases}$ の解で、$t\le0$ で $y=0$ のものを求めよ。

解答　① 7.1：$\hat y=\dfrac{1}{2+i\omega}\hat f$。

② 3.3（$a=1$）：$\hat f(\omega)=\dfrac1{\sqrt{2\pi}}\dfrac{1}{1+i\omega}$。

③ $\hat y(\omega)=\dfrac1{\sqrt{2\pi}}\dfrac{1}{(1+i\omega)(2+i\omega)}$。

④ 部分分数：$\dfrac1{(1+i\omega)(2+i\omega)}=\dfrac1{1+i\omega}-\dfrac1{2+i\omega}$。　右辺を通分すると分子 $(2+i\omega)-(1+i\omega)=1$

⑤ 3.3 を逆に読む：$\dfrac1{\sqrt{2\pi}(1+i\omega)}\leftrightarrow e^{-t}$（$t>0$）、$\dfrac1{\sqrt{2\pi}(2+i\omega)}\leftrightarrow e^{-2t}$（$t>0$）。線形性（4.1）から $y(t)=e^{-t}-e^{-2t}$（$t>0$）、$y=0$（$t\le0$）。

確かめ：$y'+2y=-e^{-t}+2e^{-2t}+2e^{-t}-2e^{-2t}=e^{-t}$。✓。$y(0)=1-1=0$（$t\le0$ の $y=0$ と連続につながる）。□

例題5（C：流派の換算）

ある本で、$f(t)=e^{-a\lvert t\rvert}$ の変換が $F(\omega)=\dfrac{2a}{a^2+\omega^2}$ と書かれている（逆変換は $\frac1{2\pi}\int F\,e^{i\omega t}d\omega$）。(1) この本の流派は何か。(2) 流派 ① の $\hat f$ に直せ。(3) 流派 ④（$e^{-2\pi i\xi t}$）の形に直せ。

解答　(1) 逆変換に $\frac1{2\pi}$ があるので、変換は前の定数が $A=1$（流派 ②）。$\omega=0$ で $F(0)=\frac2a=\int f\,dt$（面積）とも合う（2.4 の見分け方 3 点目）。

(2) 流派 ① は $A=\frac1{\sqrt{2\pi}}$ なので $\hat f=\dfrac{F}{\sqrt{2\pi}}=\dfrac1{\sqrt{2\pi}}\dfrac{2a}{a^2+\omega^2}=\sqrt{\dfrac2\pi}\dfrac{a}{a^2+\omega^2}$。3.2 と一致する。

(3) 流派 ④ は $\omega=2\pi\xi$ を代入して $\tilde f(\xi)=F(2\pi\xi)=\dfrac{2a}{a^2+4\pi^2\xi^2}$。　定数は消えない（$A=1$）。$2\pi$ は $\xi$ の中に入る

確かめ：(3) の逆変換 $\int\tilde f(\xi)e^{2\pi i\xi t}d\xi$ の $t=0$ は、$\int\frac{2a}{a^2+4\pi^2\xi^2}d\xi=\frac1{2\pi}\int\frac{2a}{a^2+\omega^2}d\omega=\frac1{2\pi}\cdot2\pi=1=f(0)$（$\omega=2\pi\xi$、$d\omega=2\pi d\xi$）。□

10演習問題

問題はすべて自作（解答も自作の解答）。A は記号を読める・書き換えられる、B は標準、C は発展。流派は特に断らなければ ①。

問1（A）

矩形パルス（$\lvert t\rvert<2$ で $1$）の変換について、(a) $\hat f(0)$、(b) 最初の零点 $\omega$ を求めよ。

解答

3.1 で $a=2$：$\hat f(\omega)=\sqrt{\frac2\pi}\frac{\sin2\omega}\omega$。(a) $\hat f(0)=\sqrt{\frac2\pi}\cdot2=\frac{4}{\sqrt{2\pi}}\approx1.596$（面積 4 を $\sqrt{2\pi}$ で割った値）。(b) $\sin2\omega=0$ で最小の正の $\omega$ は $2\omega=\pi$、すなわち $\omega=\frac\pi2$。

問2（A）

$f=e^{-\lvert t\rvert}$ について、流派 ①、②、④ の $\omega=0$（④は $\xi=0$）での値と、$\omega=2$ の値（④は $\xi=0.5$）を求めよ。

解答

①：$\sqrt{2/\pi}\frac{1}{1+\omega^2}$ で、$\omega=0$：$0.798$、$\omega=2$：$0.798/5=0.160$。②：$\frac{2}{1+\omega^2}$ で、$2$ と $0.4$。④：$\frac{2}{1+4\pi^2\xi^2}$ で、$\xi=0$：$2$、$\xi=0.5$（$\omega=\pi$）：$\frac2{1+\pi^2}\approx0.184$。

問3（A）

3.3 で $a=3$ のとき、$\omega=4$ での $\lvert\hat f\rvert$ と $\arg\hat f$ を求めよ。

解答

$\hat f=\frac1{\sqrt{2\pi}}\frac1{3+4i}$。$\lvert3+4i\rvert=5$ なので $\lvert\hat f\rvert=\frac1{5\sqrt{2\pi}}\approx0.0798$。$\arg\hat f=-\arg(3+4i)=-\arctan\frac43\approx-0.927$ rad $\approx-53.1^\circ$。

問4（A）

$\mathcal F[f]=\hat f(\omega)=e^{-\omega^2/2}$ のとき、次の変換を $\hat f$ で書け。(a) $f(t-3)$、(b) $f(2t)$、(c) $f'(t)$、(d) $e^{4it}f(t)$、(e) $f(t)\cos4t$。

解答

(a) $e^{-3i\omega}\hat f(\omega)=e^{-3i\omega}e^{-\omega^2/2}$（4.2）。(b) $\frac12\hat f(\omega/2)=\frac12e^{-\omega^2/8}$（4.5）。(c) $i\omega\,e^{-\omega^2/2}$（4.4）。(d) $\hat f(\omega-4)=e^{-(\omega-4)^2/2}$（4.3）。(e) $\frac12\bigl[e^{-(\omega-4)^2/2}+e^{-(\omega+4)^2/2}\bigr]$（4.3）。

問5（B）

$f(t)=t^2e^{-t^2/2}$ の変換を求めよ。

解答

① $g(t)=e^{-t^2/2}$、$\hat g=e^{-\omega^2/2}$（3.4）。　② 4.4 を2回：$\mathcal F[tg]=i\hat g'$、$\mathcal F[t\cdot tg]=i\,(\mathcal F[tg])'=i\,(i\hat g')'=-\hat g''$。　③ $\hat g'=-\omega e^{-\omega^2/2}$、$\hat g''=-e^{-\omega^2/2}+\omega^2e^{-\omega^2/2}$。　④ よって $\hat f(\omega)=(1-\omega^2)\,e^{-\omega^2/2}$。確かめ：$\omega=0$ で $1$。面積 $\int t^2e^{-t^2/2}dt=\sqrt{2\pi}$（部分積分）を $\sqrt{2\pi}$ で割って $1$ で一致する。

問6（B）

3.1（$a=1$）にパーセバルの等式を使って、$\displaystyle\int_{-\infty}^{\infty}\frac{\sin^2\omega}{\omega^2}d\omega$ を求めよ。

解答

① 左辺 $\int\lvert f\rvert^2dt=\int_{-1}^{1}1\,dt=2$。　② 右辺 $\int\lvert\hat f\rvert^2d\omega=\frac2\pi\int\frac{\sin^2\omega}{\omega^2}d\omega$。　③ 等式から $\frac2\pi\int\frac{\sin^2\omega}{\omega^2}d\omega=2$、よって $\int\frac{\sin^2\omega}{\omega^2}d\omega=\pi$。確かめ：片側 $\int_0^\infty\frac{\sin^2x}{x^2}dx=\frac\pi2$ は既知の値（sympy で確認）で、両側は2倍。

問7（B）

$y'+3y=f$ の周波数応答 $H(i\omega)$ と、入力 $\cos4t$ に対する定常解を求めよ。

解答

$H(i\omega)=\frac1{3+i\omega}$（7.1、$a=3$）。$\omega=4$：$H=\frac1{3+4i}$、$\lvert H\rvert=\frac15$、$\arg H=-\arctan\frac43\approx-0.927$。定常解 $y=\frac15\cos(4t-0.927)$。確かめ：入力 $e^{4it}$ で $y=He^{4it}$ とおくと $y'+3y=(4i+3)He^{4it}=e^{4it}$ で成り立つ。

問8（B）

流派 ② の変換 $F(\omega)=\int f\,e^{-i\omega t}dt$ では、パーセバルの等式は $\int\lvert f\rvert^2dt=\frac1{2\pi}\int\lvert F\rvert^2d\omega$ となることを、$f=e^{-\lvert t\rvert}$ で確かめ、なぜ $\frac1{2\pi}$ が付くかを述べよ。

解答

$F=\frac2{1+\omega^2}$。右辺 $\frac1{2\pi}\int\frac4{(1+\omega^2)^2}d\omega=\frac1{2\pi}\cdot4\cdot\frac\pi2=1$。左辺 $\int e^{-2\lvert t\rvert}dt=1$。一致する。理由：$F=\sqrt{2\pi}\,\hat f$（①と②の換算、2.4）なので $\int\lvert F\rvert^2=2\pi\int\lvert\hat f\rvert^2$。①でのパーセバルに代入すると $\frac1{2\pi}$ が付く。

問9（C）

$\alpha>0$ として $\mathcal F[e^{-\alpha t^2}](\omega)=\frac1{\sqrt{2\alpha}}e^{-\omega^2/(4\alpha)}$ を、3.4 と 4.5 から導け。

解答

① $e^{-\alpha t^2}=g(ct)$、$g(t)=e^{-t^2/2}$、$c^2/2=\alpha$ より $c=\sqrt{2\alpha}$（$c>0$）。　② 4.5：$\frac1c\hat g(\omega/c)=\frac1{\sqrt{2\alpha}}e^{-\omega^2/(2c^2)}$。　③ $2c^2=4\alpha$ より $e^{-\omega^2/(4\alpha)}$。□

問10（C）

$f(t)=e^{-ct^2/2}$（$c>0$）について、$\lvert f\rvert^2$ と $\lvert\hat f\rvert^2$ をそれぞれ（正規化した）分布と見たときの標準偏差 $\sigma_t$、$\sigma_\omega$ を求め、積が $c$ によらないことを示せ。

解答

① $\lvert f\rvert^2=e^{-ct^2}$。指数の形 $e^{-t^2/(2\sigma^2)}$（正規分布の密度の形）と比べて $2\sigma_t^2=\frac1c$、すなわち $\sigma_t^2=\frac1{2c}$。　② 問9 で $\alpha=\frac c2$：$\hat f=\frac1{\sqrt c}e^{-\omega^2/(2c)}$。$\lvert\hat f\rvert^2\propto e^{-\omega^2/c}$ なので $2\sigma_\omega^2=c$、$\sigma_\omega^2=\frac c2$。　③ 積 $\sigma_t\sigma_\omega=\sqrt{\frac1{2c}\cdot\frac c2}=\frac12$。□　（$c=1$ のとき $\sigma_t=\sigma_\omega=\frac1{\sqrt2}$。）
