GUIDE

はじめに ― このフォルダの使い方

このフォルダは、大学の授業と並行して「自習教材を自動的に育てていく」ための作業場所です。中身は空の状態からスタートします。このページでは、何も知らない状態からでも迷わず使い始められるように、手順を説明します。

全体の流れ：①このフォルダをClaude Codeで開く → ②「開始」と話しかける → ③聞かれた質問に答える／資料を渡す → ④教材と読み物コラムが2本1組で output/ に育っていく → ⑤分からないところは話しかけるだけで教材に蓄積される。

1これは何のためのフォルダか

授業の板書・スライド・シラバスなどの情報をもとに、Claude Code（AIアシスタント）が「証明・導出の過程を省略しない」自習用教材（HTML）をこのフォルダの中で作っていく仕組みです。数学に限らず、証明・導出を重視する授業であれば流用できます。

2フォルダ構成

フォルダ役割
inbox/まだ整理していない資料の一時置き場
reference/シラバス・スライド・過去問など参考資料の保管場所
draft/作成途中の下書き・作業用スクリプト
output/完成した教材HTML（このガイドもここに入っています）。写真は output/img/
output/column/各回の読み物コラム（写真は output/column/img/）
templates/教材・コラム・目次の雛形と「コラムの作り方」。Claude Code が毎回ここから作る（普段は触らなくてよい）
archive/使い終わった・不要になった素材の退避先（勝手に削除はしない）
CLAUDE.mdClaude Codeが自動的に読み込む作業ルール（すでに用意済み・普段は編集不要）
.claude/skills/Claude Codeの拡張機能（スキル）。詳しくは6章

3はじめの一歩

やること
  1. このフォルダ全体をコピーして、新しい授業用の名前（例：「流体力学」）に変える。
  2. Claude Codeで、そのフォルダを作業ディレクトリとして開く。
  3. チャットで 「開始」 と話しかける。

「開始」と言うと、Claude Codeは CLAUDE.md に書かれた手順（§11）にしたがって、以下のようなことを質問してきます。答えられる範囲でよいので答えてください。

  • 科目名・授業の対象
  • 担当教員の方針（公式の暗記重視か、証明・導出重視か 等）
  • シラバス（全体の回数・各回のテーマ）
  • 使う教科書・資料の入手方法
  • 試験やレポートの有無・頻度
なぜ最初に質問されるの？ Claude Codeは授業内容そのものを知りません。最初にヒアリングすることで、その科目専用に CLAUDE.md（作業ルール）を書き換え、以降は科目の文脈を踏まえた教材を作れるようになります。分からない項目は「まだ分からない」と答えて構いません。あとから追加で伝えることもできます。

4資料の渡し方

シラバス・板書メモ・スライドの写真・過去問などは、reference/ フォルダに保存し、Claude Codeに「reference/に◯◯を入れました」と伝えてください。inbox/ にとりあえず放り込んでおいて、あとで整理をClaude Codeに頼むのでも構いません。
注意 試験問題やスライドの写真は著作権・再配布の観点があります。教材本体に丸ごと転記するのではなく、出典を明示しつつ内容を自分の言葉で説明し直す形にするのがおすすめです（Claude Codeにもそのように依頼しています）。

5教材ができあがっていく様子

1回分の授業ごとに、次の2本が1組で増えていきます。全体は目次 output/index.html で一覧でき、各回の行に「教材｜読み物」が並びます。
  • 教材 output/NN_第N回_タイトル.html：導出の筋道を省かずに説明し直したもの。冒頭には、その回を象徴する異分野の写真（扉）があり、各章には「現実｜見立て」の写真の見開きが1つずつ入ります。
  • 読み物コラム output/column/CNN_….html：講義の一手から出発して、思想史・美術・宗教などへ遠く跳ぶ読み物（5,000〜7,000字）。
教材と読み物の行き来 どちらのページも、画面の右下に小さなボタンが常に出ています。教材では「目次｜読み物 →」、読み物では「目次｜← 教材」。読んでいる途中でも、ワンタップで行き来できます。

6分からないところがあったら（ティーチングモード）

使い方 特別なコマンドを覚える必要はありません。教材を読んでいて分からない箇所があれば、そのままチャットで
「ここが分からない」「〇〇ってどういうこと？」「この証明のこの行が分からない」
のように話しかけるだけで大丈夫です。
裏側で起きていること このフォルダには .claude/skills/teaching-mode/ という「ティーチングモード」スキルが同梱されています。上のように話しかけると、Claude Codeが自動的にこのスキルを使い、①その場で説明する、②説明した内容を該当する教材HTMLに「🙋 質問から追加：」という印つきで書き足す、という2つを行います。これにより、自分がつまずいた点が教材に残り、あとで見返して復習できます。スキルという言葉やコマンドを知らなくても、普通に質問するだけで発動します。
まだ試作段階 このティーチングモードは試作したばかりで、実際の質問での動作確認は十分ではありません。追記のされ方が期待と違う場合は、Claude Codeに直接「さっきの追記はやり直して」のように伝えてください。

7よくある質問

数学以外の科目でも使える？

使えます。CLAUDE.mdの証明・導出重視のルールや、数式表示（MathJax）の仕組みは、数式や導出過程を扱う授業（物理・工学系など）であれば流用できます。逆に、暗記中心・数式をほぼ使わない科目では、ルールの一部（§8・§9）を書き換えたほうがよい場合があります。

CLAUDE.mdは自分で編集していいの？

問題ありません。最初のヒアリング後は科目専用の内容になっているはずですが、教員の方針が分かった／変わった等があれば、Claude Codeに「CLAUDE.mdのここを直して」と頼めば更新してもらえます。

完了チェックボックスや進捗バーは付けられる？

このテンプレートには含めていません（使い勝手が芳しくなかったため、6章のティーチングモードで代替する方針にしました）。どうしても欲しい場合はClaude Codeに個別に相談してください。
